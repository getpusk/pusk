# История изменений

## [0.7.8] - 2026-04-19

### Security
- **P0**: Устранён оракул перечисления имён пользователей — `/api/my-orgs` больше не вызывается с лендинга, добавлен server-side rate-limit
- **P1**: Исправлена JSON-инъекция в admin-ответах об ошибках — используется хелпер `jsonErr()` вместо конкатенации строк
- **P1**: Исправлена nil-pointer паника при регистрации организации — добавлены проверки ошибок после операций store/auth/token
- **P1**: Исправлено сопоставление ACK на длинных сообщениях — проверяются только последние 80 символов на маркеры ACK/Resolved/Muted

### Changed
- Удалено 142 строки мёртвых format-функций из `webhook.go` (заменены движком шаблонов)
- Исправлена утечка горутины `time.Tick` в `route.go` — используется `time.NewTicker`
- Закрывается тело HTTP-ответа в пути ошибки push-уведомлений
- Переписан `templates_test.go` для тестирования через API движка шаблонов

### Docs
- Скриншот лендинга заменён реальным workflow-GIF (создание орга → вход → алерты → ACK → настройки)
- Добавлена спецификация записи скринкаста для воспроизводимых README-ассетов

## [0.5.0] - 2026-03-20

### Added
- Ответы в каналах (командная координация)
- Кнопки ACK/Mute/Resolved на алертах
- Вебхук-эндпоинт: Alertmanager, Zabbix, Grafana, Uptime Kuma
- Умный парсер JSON-пэйлоадов (msg/message/text)
- sendMessage → канал по отрицательному chat_id
- Инвайт-ссылки (одноразовые, TTL 24 часа)
- Мультитенантность (SQLite на организацию)
- Регистрация организаций (системный бот + #general)
- Webhook Relay через WebSocket
- Лендинг с демо-чатом
- PWA-установка

### Security
- bcrypt, случайный JWT-секрет
- Rate limit 20/мин на IP
- IDOR-защита, SSRF-валидация
- XSS: только http/https ссылки
- JWT для файлов, валидация Origin (WebSocket)
- Graceful shutdown (SIGTERM → 5 сек)

### CI/CD
- CodeQL, govulncheck, Trivy
- Интеграционные тесты, OpenSSF Scorecard
- 34 E2E-теста Playwright
